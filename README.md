# SenCha930511 omp marketplace

A plugin marketplace for [omp (oh my pi)](https://github.com/oh-my-pi/omp).

## Use this marketplace

```sh
omp plugin marketplace add SenCha930511/omp-marketplace
omp plugin install pi-model-sync@sencha930511
```

## Plugins

| Name | Description |
|---|---|
| [pi-model-sync](https://github.com/SenCha930511/pi-model-sync) | Route subagent models by the spawning session's current model (omp native subagents + pi-subagent), managed via `/model-sync` |

Catalog source: [`.omp-plugin/marketplace.json`](.omp-plugin/marketplace.json). To add a plugin, open a PR against the catalog.
